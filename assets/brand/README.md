# Navyakta AI brand

Navyakta = navya (new) + vyakta (voiced). The mark is a glass voice orb holding an "n" whose voice trails off in two bars.

| File | Use |
| --- | --- |
| `navyakta-mark.svg` | Symbol on its own: app icon, favicon, avatar |
| `navyakta-mark-512.png`, `navyakta-mark-1024.png` | Symbol for social profiles and stores (transparent) |
| `navyakta-logo.svg` / `.png` | Full logo on light backgrounds (transparent) |
| `navyakta-logo-dark.svg` / `.png` | Full logo on dark backgrounds (transparent, white text) |

The wordmark in the SVGs is outlined, so it needs no font installed.

**Colours:** ink `#141414`, lime `#DCF27A`, lavender `#BCAEF7`, paper `#F2F2EE`. Orb gradient `#F3FCC8` → `#D3F062` → `#9C86EE`.

**Type:** Geist (wordmark Semibold, tight tracking, lowercase), Geist Mono for small labels.

The website draws the same mark in code: `LogoMark` in `frontend/src/portal/Landing.tsx`.
